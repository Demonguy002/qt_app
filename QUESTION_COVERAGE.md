## Why the practice bank is intentionally limited

The original screenshot example (Exercise 1, Question 29) was misread by the previous OCR import. The printed question is `217 x 217 + 183 x 183 = ?`, the printed options include `80578`, and the answer is option B. The checked solution is `2 x (200² + 17²) = 80,578`. The incorrect OCR version is not retained as a playable card.

The app shows only cards with all three flags set: `questionVerified`, `answerVerified`, and `solutionVerified`. The rest of the source book can be browsed by selecting the original PDF file in Book Library. It remains local to the browser and is not deployed as a publicly downloadable textbook.
